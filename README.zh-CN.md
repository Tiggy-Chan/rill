# Rill

Rill 是一个小巧的 macOS 原生应用，可以把一段视频设为桌面壁纸。它只在菜单栏显示图标，平时不打扰你，壁纸看不见时会自动暂停。

## 功能

- **所有显示器都能显示动态壁纸。** 视频在系统壁纸之上、桌面图标之下。切换桌面空间时一直都在，也不会挡住鼠标点击。运行中接上或拔掉显示器都没问题。
- **循环无缝，占用低。** 循环播放没有间隔，用硬件解码，默认静音。在 Apple Silicon 上测试，循环播放 4K H.264 视频大约只占 2% CPU。
- **菜单栏面板简洁。** 有实时预览、播放/暂停、静音和音量，以及填充、适应、拉伸三种画面模式。
- **设置方便。** 可以在面板里选择文件，把视频拖到菜单栏图标上，或者在访达里用「打开方式 › Rill」。
- **看不见时自动暂停。** 显示器休眠、锁屏、壁纸被窗口完全遮挡时都会暂停。也可以设置在用电池或开启低电量模式时暂停。
- **记住你的选择。** 下次启动时恢复视频和设置。视频文件被重命名或移动过也能找到。
- **可选登录时启动。** 默认关闭。
- **注重隐私。** 不联网，不收集任何数据。设置只保存在本机的偏好设置 `com.tiggychan.rill` 里。

## 系统要求

- macOS 14 Sonoma 或更高版本
- 编译需要 Swift 6 工具链：安装 Xcode 16 或更高版本，或者只装命令行工具（`xcode-select --install`）

## 编译和安装

目前还没有预编译的版本，需要从源码编译：

```sh
git clone https://github.com/Tiggy-Chan/rill.git
cd rill
./Scripts/build.sh                  # 生成 build/Rill.app
cp -R build/Rill.app /Applications/
open /Applications/Rill.app
```

应用只做了 ad-hoc 签名，没有经过公证。在编译它的那台 Mac 上可以直接打开；拷贝到别的 Mac 上可能会被 Gatekeeper 拦截。

## 使用方法

1. 点击菜单栏里的水滴图标，打开面板。
2. 点击「选择视频…」或预览区域，或者把视频拖到菜单栏图标上。
3. 在面板里调整壁纸：
   - 播放/暂停按钮、静音按钮和音量滑块
   - 「画面」：填充 · 适应 · 拉伸
   - 「用电池或低电量模式时暂停」
   - 「登录时启动」
4. 点击面板外的任何地方或按 Esc 关闭面板。

「更换视频…」可以换一个文件，「移除」会关闭视频壁纸，「退出」会退出应用。Rill 不会修改系统壁纸设置，所以移除视频或退出后，原来的壁纸就会回来。

Rill 能播放 AVFoundation 支持的所有格式，比如 `.mp4`、`.mov`、`.m4v` 文件里的 H.264 或 HEVC 视频。使用「填充」时，视频比例越接近屏幕比例，被裁掉的部分越少。

## 工作原理

Rill 为每块显示器创建一个无边框窗口，放在比桌面窗口高一层的位置，所以视频夹在系统壁纸和访达的桌面图标之间。这些窗口不响应鼠标，并且出现在所有桌面空间里。所有显示器共用一个 `AVPlayer`，多接显示器也不会增加解码负担。什么时候播放由一个带单元测试的小策略决定，它综合了你的手动暂停、显示器休眠、锁屏、窗口遮挡和电源状态。

## 开发

```sh
./Scripts/build.sh      # 低优先级的 release 编译(可用 CONFIG=debug、JOBS=n 覆盖)
./Scripts/test.sh       # 单元测试(Swift Testing)，只装命令行工具也能运行
./Scripts/make-icon.sh  # 用 Scripts/make-icon.swift 重新生成 Resources/AppIcon.icns
```

```
Sources/Rill/
├─ MenuBar/     菜单栏图标和弹出面板
├─ UI/          SwiftUI 面板
├─ Wallpaper/   桌面层级的窗口，每块显示器一个
├─ Playback/    循环播放器、暂停策略和系统状态监听
└─ Settings/    设置的保存和读取
```

## 卸载

1. 如果开着「登录时启动」，先在面板里关掉。
2. 退出 Rill，删除 `Rill.app`。
3. 如果需要，删除它的设置：`defaults delete com.tiggychan.rill`
